# T12: the sky stage (v0.3)

Branch `T12` (from main after T11). This ports the D1 3D into production modules, driven by the T11 scroll engine.

## What changed
- **`components/stage/sky-host.tsx`:** mounted once in `__root.tsx`. It stays **dormant** until a page calls `useRequestSky()` (owner decision a): no WebGL and no 3D code is loaded before that. Once started, the sky stays alive across navigation, so legacy pages with their own canvases never run two canvases at once. A `WebglBoundary` falls back to the plain void.
- **`components/stage/sky-stage.tsx`:** the one canvas.
  - `frameloop="never"`, advanced from the scroll engine's `afterScroll`, so the 3D and the DOM share a frame (S5).
  - DPR per tier: 1.75 / 1.5 / 1.
  - drei `PerformanceMonitor` steps the tier down when frames drop.
  - Labels render into a fixed layer above the canvas.
- **`components/stage/starfield.tsx`:** far shell + flight layer + dust, with star counts per tier (PLAN §7: 6000 / 2500 / 900 shell).
- **`components/stage/star-points.ts` + `field-points.tsx`:** the shared point shader (crisp, no bloom, linear output), plus deterministic fields and palette colours.
- **`components/stage/effects.tsx` + `crawl-effect.ts`:** the scroll-locked bite crawl (reads `store.transition` and `store.grain`), grain 0.03 and vignette. **No bloom.**
- **`components/stage/camera-rig.tsx`:** pointer parallax.
- **`components/objects/glass-hound.tsx`:**
  - custom glass shader, cursor-only motion
  - `scene.houndAway` → exponential recede (`recedeDepth` in `lib/motion/math.ts`, tested)
  - curve segments per tier
  - still the **draft silhouette**
- **`components/objects/canis-major.tsx`:**
  - J2000 positions (`lib/stage/canis-major.ts`)
  - burst from the hound, sequential lines, static Bayer labels (`bayer` + `label` utilities)
  - narrow-screen fit
- **`lib/stage/store.ts`:** adds `sky`, `transition`, `grain` and the `scene` channels (houndAway, canisOn/Form/Lines/Labels/Away, flight). This is the whole contract between copy and sky.
- **`lib/stage/request-sky.ts`:** `useRequestSky(mode)`.
- **`/_stage`:** a throwaway check page (delete in T52). It maps section progress to scene channels with the D1 values; T14 will own this mapping.
