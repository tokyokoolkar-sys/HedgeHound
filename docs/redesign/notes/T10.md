# T10: DESIGN.md tokens and type (v0.3)

Branch `T10-almagest` (from main). Supersedes the old `T10` branch (parchment/glass), whose plumbing was reused.

## What changed
- **Tokens** (`src/styles.css` `@theme`, mirrored in `src/lib/palette.ts`, guarded by `src/lib/palette.test.ts`): void, starlight (+ dim 0.62, faint 0.38), chart line, scan, scent, star tints.
- **Legacy pages keep their v1 palette** (owner decision 1b). The v1 `muted` token was renamed `v1-muted`, because `muted` is shadcn's surface token; 58 usages were updated, and `palette.muted` became `palette.v1Muted`.
- **Two fonts only** (decision 2): Noto Serif Display Variable + JetBrains Mono Variable. Syne, Fraunces, Bricolage, Pinyon and Inter were uninstalled. `--font-sans` and `--font-serif` both point to the display face, so the legacy pages switched too.
- **Type scale:** hero, chapter, title, subtitle (330), body (330), label (11px minimum), figure, bayer (13px/400). Utilities: `label`, `figure`, `bayer`, `font-light-display`. A `--tracking-tag` token was added.
- **shadcn mapping:**
  - primary = starlight, destructive = scent, ring = scan
  - border at 14%, input at 40% (3.4:1)
  - popovers and cards are void with a hairline border
  - dark variants always on
- **Buttons:** the main CTA is a starlight hairline (outline). There is no orange button (critique decision).
- **SourceTag:**
  - built on the `label` role, weight 400, `tracking-tag`
  - inherits colour; LIVE at full strength, SAMPLE/PAPER at 0.75
  - `ts != null` check
- **magicui:** colour defaults now use tokens. SVG `stopColor`/`stroke` moved to style, because presentation attributes don't resolve `var()`.
- **@spell/shimmer-text and @spell/logos-carousel** ported from D1, including the `<style jsx>` fix.
- **`/_kitchen` specimen:**
  - swatches checked against their real use: text 4.5:1, non-text 3:1
  - the type scale, SourceTag states, ShimmerText, the carousel and the button mapping
  - the page's own chrome moved off legacy tokens

## DESIGN.md updates (owner decisions from the T10 critique)

- The Quiet Action Rule: the CTA is a starlight hairline, and nothing else is orange.
