## Changes from the source (and why)
1. **`@/lib/utils` → `@/lib/cn`** (ticket). Done in `gradient-wave-text.tsx`.
2. **Gradient colours.** WhaleHunterAlt used violet, teal and yellow stops (`oklch(0.72 0.2 300)`, `oklch(0.8 0.14 200)`, `oklch(0.82 0.14 85)`). The ticket allows only starlight and dim tones, never `--scent` or `--scan`. The stops are now `var(--color-muted)` (dim) and `var(--color-fg)` (starlight), from the existing `@theme` tokens. T10 will switch to `--dim` and `--starlight`. No hex in the CSS.
3. **Perspective effect colours.** The source hard-codes `#F7F4F2` (background), `#7B9E87` (text) and `bg-[#F7F4F2] text-[#7B9E87]`. Hex is not allowed outside `src/lib/palette.ts` (CLAUDE.md, rule 5). Now `bg-bg text-fg` and `var(--color-bg)` in the overlay.
4. **Perspective effect, reduced motion.** It now checks `prefers-reduced-motion` in the effect. When reduced, no scroll mapping runs, and the text is shown at the readable mid-state (progress 0.5: opacity 1, no tilt).
5. **Perspective effect, cleanup.** The effect captures `stateRef.current` in a local `state` before the cleanup, which fixes a `react-hooks/exhaustive-deps` warning. Behaviour unchanged.
6. **`"use client"` directive** dropped from the perspective file (Next.js only; no effect in this Vite app).
7. **Shiny text colours and keyframes.** The magicui registry uses neutral palette classes (`text-neutral-600/70`, `dark:text-neutral-400/70`, `via-black/80`, `dark:via-white/80`). Changed to tokens: `text-muted/70` and `via-fg/80`; the `dark:` variants were removed (the site is dark-only). The keyframes and `animate-shiny-text` were moved out of `styles.css` into `animated-shiny-text.css` (`.text-fx-shiny`), because `shadcn add` wrote them into `styles.css` and the ticket says not to touch that file. The `styles.css` change was reverted.
8. **Gradient wave reduced motion.** The CSS stops the wave under `prefers-reduced-motion: reduce`, so the text stays a static gradient.
