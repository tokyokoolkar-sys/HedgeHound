## Blocker: `npm run dev` fails on Windows
Command: `npm run dev` (runs `node scripts/with-app-env.mjs vite dev --host 0.0.0.0 --port 8080`)

Exact output:
```
npm notice run dev
npm notice run node scripts/with-app-env.mjs vite dev --host 0.0.0.0 --port 8080
[with-app-env] failed to run vite: spawn vite ENOENT

[exited with code 127]
```

Diagnosis (no files edited):
- `scripts/with-app-env.mjs` calls `spawn(command, args, { stdio: "inherit", env })` with no `shell` option.
- On Windows, `node_modules/.bin/` holds `vite`, `vite.cmd` and `vite.ps1`. Node's `spawn("vite")` finds none of them, so it returns `ENOENT`.
- Calling `spawn("vite.cmd")` directly fails differently: `Error: spawn EINVAL` (Node refuses to run `.cmd` shims without a shell).
- Node v26.7.0, npm 12.0.2.

Options for the owner (none applied, since the ticket says stop):
1. Add `shell: process.platform === "win32"` to the `spawn` options in `scripts/with-app-env.mjs`. This is a one-line change to a file this ticket does not list, so it needs an OK.
2. Run `npx vite dev --host 0.0.0.0 --port 8080` directly. This skips the `.grok/app-env.json` merge (`VITE_AUTH_ENABLED=false`), so auth would be on.
