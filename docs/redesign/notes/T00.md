- Round 2 (owner-approved fix): `package.json` scripts now run vite through node, so no shell is needed:
  - `dev`: `node scripts/with-app-env.mjs node node_modules/vite/bin/vite.js dev --host 0.0.0.0 --port 8080`
  - `build`: `node scripts/with-app-env.mjs node node_modules/vite/bin/vite.js build && npm run db:migrate`
