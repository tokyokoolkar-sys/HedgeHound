# T11: the scroll engine (v0.3)

Branch `T11` (from main after T10).

## What changed
- **`src/lib/motion/scroll-engine.tsx`:** `<ScrollEngine/>`, mounted once in `__root.tsx`. It renders nothing; everything happens in a client-only effect.
  - **Lenis on `gsap.ticker`:** lerp 0.075, wheel multiplier 0.9 (D1 values). Mouse wheel only: `syncTouch: false`, so touch keeps native scroll (owner decision).
  - **S5 fixes:** `lenis.reset()` before `destroy()`; `lagSmoothing(0)` only while Lenis runs, restored after.
  - **Reduced motion:** Lenis turns off and on with `prefers-reduced-motion`, live, and `html.lenis` is removed cleanly.
  - **Re-measuring:** a debounced (120 ms) `ResizeObserver` on `<body>` plus window resize, so late fonts and content don't leave stale offsets.
  - **Pointer:** smoothed with frame-rate-independent `damp` (λ 3.5).
  - **Tick order:** `lenis.raf` → section progress + pointer written to the store → `afterScroll` callbacks.
- **`src/lib/motion/scroll-progress.ts`:** section registry (`useSection(id)` ref callback, `registerSection`, `measureSections`, `readSections`).
- **`src/lib/motion/math.ts`:** pure maths: `sectionProgress`, `activeIndex`, `band`, `smooth`, `clamp01`, `damp`. There are no clocks, so progress is a function of the scroll position only.
- **`src/lib/motion/quality.ts`:** `pickTier` (pure) and `detectTier` (browser). Phone width, touch-first, ≤4 cores or ≤4 GB gives mid; weak CPU plus low memory gives low.
- **`src/lib/motion/scroll-bus.ts`:** `afterScroll`, `getLenis`, `scrollToTarget` (kept out of the component module, per S5).
- **`src/lib/motion/use-reduced-motion.ts`:** a live hook.
- **`src/lib/stage/store.ts`:** the stage store from PLAN §4.3, plus `sections`, `active` and `smooth`.
- **`/_motion`:** a throwaway check page (delete in T52). It shows section bars, a HUD, and a dot whose position is a pure function of α progress, driven from `afterScroll`.

## Verification
- typecheck clean; lint shows only the pre-existing `no-empty`; `npm test` 304/304 (+11 in `motion.test.ts`)
- Playwright on `/_motion`:

| | Chromium desktop | Firefox 151 desktop | Chromium iPhone 13 |
|---|---|---|---|
| α progress at target | 0.397 (scroll 2511 = 2790 × wheel 0.9; matches the maths) | 0.397 | 0.500 (native scroll, exact) |
| scroll mode | lenis | lenis | lenis (wheel only), touch native |
| tier | high | high | mid |
| frozen when idle (1.5 s) | yes | yes | yes |
| reduced motion at runtime | native, `html.lenis` removed | same | same |
| restored | lenis, `html.lenis` back | same | same |
| errors | none | none | none |

- Legacy pages with the engine on: `/` and `/den` wheel-scroll normally with no errors. `/universe` is a fixed full-screen view.
