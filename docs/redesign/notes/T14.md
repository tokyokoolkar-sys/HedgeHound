# T14: Overture + α Canis Major + the α→β crawl (v0.3)

Branch `T14` (from main after T13).

## Owner decision
- **(b):** the hero resolves from blur on page load. The title is a single word, so it resolves as one block, followed by the subtitle word by word and then the scroll cue. This is the only entrance not tied to the scroll. It's done in CSS (`.intro-resolve` in `styles.css`), so it plays on first paint with no flash and no JS dependency. It's disabled under reduced motion.

## What changed
- **Overture:**
  - CSS intro (title block, subtitle words staggered 120 ms, cue at 1.9 s)
  - the scroll cue `Scroll ↓ α` leaves with the first scroll
  - glass hound smaller and higher on phones (scale 0.5)
- **α Canis Major:**
  - content timing: `rise [0.34, 0.5]` (the copy waits for the constellation), `titleReveal [0.42, 0.52]`, `bodyWords [0.44, 0.56]` (word-by-word resolve, `wordLook` in `choreo.ts`)
  - exits upward during the crawl, fading before the nav (T13)
- **α→β crawl:** `components/edition/symbol-carousel.tsx`.
  - At full grain (crawl 0.26–0.74), `@spell/logos-carousel` cycles the coins in fives.
  - Each coin shows its net APR (`formatNet`, true minus): orange if alerting, dim while building.
  - One LIVE/SAMPLE tag covers it, and the featured coin is excluded.
- **`lib/scan/loudest.ts`:** `pickLoudest` (clean scent first, else the loudest still building) and `carouselRows`, shared with T15's reading so the featured coin and the carousel always agree.
- **Page background:** void instead of the legacy brown (the first paint showed brown before the sky loaded). `theme-color` now comes from `palette.void` (no hex in `__root`). The legacy pages paint their own backgrounds, so they look the same.
